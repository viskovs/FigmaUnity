# Security Policy

Текущая версия является ранним MVP и не предназначена для обработки секретных
данных. Описание модели доверия и ограничений находится в
[docs/security.md](docs/security.md).

Не публикуйте Figma tokens, GitHub tokens или внутренние project credentials в
issues. Для сообщения об уязвимости используйте приватный канал связи с владельцем
репозитория.
